# Glossary

| Term | Meaning |
| --- | --- |
| Session | One captured screenshot and the work and results associated with translating it. |
| Region | One independently identified text area within a screenshot. Repeated words in separate places are separate regions. |
| Original screenshot | The captured screen used as the visual reference and viewer background. |
| Annotated screenshot | A copy of the original marked with region boundaries and identifiers. |
| Source text | The reading of the original text in a region, including a correction when recognition was mistaken. |
| Raw OCR | The initial recognized text before contextual correction. |
| Translation | The English rendering of one region's source text. |
| Details island | The compact floating panel showing a selected region's source and full translation. |
